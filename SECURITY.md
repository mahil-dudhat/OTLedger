# Security Policy

## No Warranty
OTLedger is offered "as is" and without any guarantee or warranty pertaining to its operation. Because this is a **Beta Release**, there may be unforeseen bugs or security vulnerabilities. While every reasonable effort is made to ensure the product remains secure, users are ultimately responsible for conducting their own evaluations before use. The publisher accepts no liability for data loss or security breaches.

## Recommendations
Administrators must adhere to industry best practices concerning the secure operation of software. When testing or deploying this beta, please ensure you:
*   **Do not expose your OTLedger installation to the public Internet.** It should remain strictly on a local network or VPN.
*   Do not permit multiple users to share a single account.
*   Enforce strong, complex passwords for all accounts, particularly the database and admin accounts.
*   Prohibit access to the database from any client other than the OTLedger application container itself.
*   Keep your deployment updated whenever a new version is provided.

## Reporting Issues & Vulnerabilities
If you encounter any bugs, issues, or believe you've uncovered a security vulnerability, please report it by opening an **Issue** on our project repository.

Please ensure that your report meets all the following conditions:
*   Affects the most recent beta release of OTLedger.
*   Affects an instance installed and configured strictly following this official documentation.
*   Is reproducible following a prescribed set of instructions.

Please note that we DO NOT accept reports generated by automated tooling which merely suggest that a file may be vulnerable under certain conditions.
